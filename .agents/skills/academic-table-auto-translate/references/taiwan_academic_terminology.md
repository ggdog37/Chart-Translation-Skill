# 臺灣學術習慣繁體中文慣用語指南

本手冊專門提供給 AI 模型在處理「外文學術圖表與模型架構圖」時之繁體中文翻譯規範。
所有翻譯皆以**臺灣學術界（國科會、中研院、教育部、大專院校學術期刊）**之通用慣用語為唯一準則，嚴格杜絕中國大陸簡轉繁詞彙。

---

## 1. 統計學與資料科學 (Statistics & Data Science)

| 英文術語 | 臺灣學術慣用語 (標準) | 禁用 / 大陸簡轉繁詞彙 | 說明與範例 |
| :--- | :--- | :--- | :--- |
| **Cluster / Clustering** | **分群、群聚** | 聚類 | 如「分群分析 (Cluster Analysis)」 |
| **Variance** | **變異數** | 方差 | 如「變異數分析 (ANOVA)」 |
| **Covariance** | **共變異數** | 協方差 | 如「共變異數分析 (ANCOVA)」 |
| **Standard Deviation** | **標準差 ($SD$)** | 標準差 | 常縮寫為 $SD$ 或 $s$ |
| **Hypothesis Testing** | **假設檢定** | 假設檢驗 | 不使用「檢驗」 |
| **Post-hoc Test** | **事後檢定** | 事後檢驗 | 如 Scheffé、Tukey 事後檢定 |
| **Data / Dataset** | **資料、資料集** | 數據、數據集 | 臺灣學術界通稱「資料」，非一律稱數據 |
| **Significance Level** | **顯著水準 ($p$ 值)** | 顯著性水平 | 如 $p < .05$ 達顯著水準 |
| **Factor Loading** | **因素負荷量** | 因子載荷 | 因素分析 (Factor Analysis) |
| **Regression Coefficient** | **迴歸係數 ($\beta$)** | 回歸係數 | 臺灣用「迴」字 |
| **Residual** | **殘差** | 殘差 | |
| **Sample / Sampling** | **樣本 / 抽樣** | 樣本 / 抽樣 | |

| :--- | :--- | :--- | :--- |

| **Closeness Centrality** | **接近中心性** | 緊密中心度、接近度 | 衡量節點至其他節點之捷徑距離 |
| **Eigenvector Centrality** | **特徵向量中心性** | 特徵向量中心度 | |
| **Node / Vertex** | **節點 / 頂點** | 節點 / 頂點 | |
| **Edge / Link / Tie** | **邊 / 連繫 / 連結** | 連線 / 關聯 | 網絡關係通常稱為「連繫 (Tie)」 |
| **Density** | **網絡密度** | 密度 | |
| **Cohesion** | **凝聚力、凝聚度** | 內聚性 | |
