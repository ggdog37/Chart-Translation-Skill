# 學術三線表 (Booktabs) 與雙語排版規範指南

本文件定義學術三線表（Academic Three-Line Table / Booktabs）之排版規範，適用於期刊論文統計表、ANOVA 檢定表、迴歸分析表與分群指標表等。

---

## 1. 學術三線表核心線條規範

符合 APA 7th Edition 與國際期刊標準的表格樣式：

1. **頂線 (Top Rule)**：粗實線（2.0px ~ 2.2px），顏色 `#111111`。
2. **欄位底線 (Mid Rule / Heading Rule)**：細實線（1.0px ~ 1.2px），顏色 `#111111`，位於 `thead` 最後一列下方。
3. **底線 (Bottom Rule)**：粗實線（2.0px ~ 2.2px），顏色 `#111111`，位於表格最底部。
4. **絕對嚴禁垂直線 (No Vertical Lines)**：學術表格中絕不得出現任何垂直隔線（Vertical Borders）。
5. **少用內部水平線**：僅可在群組劃分（如分類彙總、總計）時使用極細淡灰色橫線（0.8px, `#cbd5e1`）。

---

## 2. 欄位與數字對齊原則

- **標題欄 (Header)**：
  - 首欄（變項名稱）靠左對齊。
  - 數值指標欄（$M$, $SD$, $t$, $F$, $p$, $\beta$）置中或靠右對齊。
- **內容資料列 (Body Cells)**：
  - 文字描述欄位靠左對齊。
  - 數值欄位靠右對齊，小數點位數必須一致（例如均保留兩位或三位）。
  - 對角線或無資料數值使用標準長破折號 `–` (en-dash) 或 `—` (em-dash)。

---

## 3. 雙語版面佈局規則

1. **英文在前，中文在後**：
   - 短標籤與變項簡稱：採同行接續（`Variable 變項`、`Table 1 表 1`）。
   - 較長句子或定義說明：中文強制斷行置於英文正下方（`.zh-block`）。
2. **統計符號與數學變數規範**：
   - 變數符號一律維持斜體（Italic），不可翻譯或擅改大小寫：
     - *N*, *n*, *M*, *SD*, *F*, *p*, *t*, *r*, *R*², *β*, *df*, *SE*
   - 顯著性星號規範：`* p < .05`, `** p < .01`, `*** p < .001`，星號置於數值右上角或緊隨其後。
3. **字型搭配**：
   - **英文、數字與統計符號**：`Times New Roman`, serif
   - **中文文字**：標楷體 (`DFKai-SB`, `BiauKai`, `標楷體`, `KaiTi`, serif)
